「スマホで27Bが動く」ってどういうこと？
── 巨大AIを3.9GBに圧縮
AI圧縮・エッジAI
🌱 やさしく解説
ChatGPTのような賢いAIはとても大きなコンピュータで動いています。「27Bパラメータ（270億個のパラメータ）」のAIモデルというのは、かなり高性能な部類で、通常はデータセンターの大型サーバーでないと動きません。ところが2026年7月、米スタートアップ「PrismML」はこの27Bパラメータのモデルをたった3.9GBに圧縮し、スマートフォン単体で動かすことに成功しました。モデル名は「Bonsai 27B（ボンサイ27B）」です。「パラメータ」とはAIの賢さを決める内部の数値の数のこと。数が多いほど賢いとされています。（出典：PrismML 公式発表 / Decrypt / Medium・2026年7月）
  • ① 27Bパラメータのモデルが「音楽アルバム1枚分」のサイズに
    通常、27Bパラメータのフル精度モデルは50GB以上のデータ量になります。Bonsai 27Bの1ビット版はそれを3.9GB（テルナリ版は5.9GB）まで圧縮しました。一般的な音楽アルバム1枚（約100曲・高音質）がだいたい3〜5GBなので、AIの「頭脳」がそのくらいのサイズに収まったということです。（出典：PrismML 公式 / LLM Configurator・2026年7月）
  • ② ベースは中国発オープンソースモデル「Qwen3.6 27B」
    Bonsai 27Bは、アリババが公開しているオープンソース（誰でも使えるコードで公開されている）AI「Qwen3.6 27B」を元に作られています。PrismMLは独自の圧縮技術をこのモデルに適用し、スマートフォンで動くサイズに仕上げました。Qwenモデルはグローバルに使われているオープンソースの高品質AIです。（出典：Medium / LLM Configurator・2026年7月）
  • ③ クラウドなし・通信なし・無料で動くAI
    Bonsai 27Bはスマホ本体の中だけで完結して動きます。つまりインターネット接続なしでAIが使えます。これは「エッジAI（クラウドに頼らず端末上で動くAI）」と呼ばれる方向性です。プライバシーの観点からも魅力があります。会話や入力データが外部のサーバーに送られないため、個人情報や機密データを扱う場合に有利です。（出典：Decrypt / Layer3Labs・2026年7月）
✏️ 中学生的に言うと：「バカでかいAIを超圧縮してスマホに入れちゃった。ネットなしでも使えるし、会話内容がどこかのサーバーに送られない。」

どうやって小さくした？
── 「1ビット量子化」という圧縮の技術
技術しくみ
🌱 やさしく解説
AIモデルの「パラメータ」は通常、精度の高い数値（32ビット浮動小数点数）で記録されています。数値1つに32ビット＝4バイトのデータが必要です。これをもっと少ない情報量で近似する方法を量子化（クオンタイゼーション）と言います。Bonsai 27Bが使ったのは「1ビット量子化」と呼ばれる極端な圧縮技術で、1つのパラメータをたった1か2ビット（「0か1」または「-1・0・+1」のどれか）に丸める方法です。これによりデータ量が元の約1/16以下になる一方で、精度が落ちすぎないよう工夫がされています。（出典：Medium / Developers Digest・2026年7月）
  • ① 「1ビット版」と「テルナリ（3値）版」の2種類
    Bonsai 27Bには2つのバリアントがあります。1ビット版（3.9GB）はより小さく、テルナリ版（5.9GB）はパラメータを「−1・0・+1」の3値で表し、精度が高くなっています。スマホのストレージや性能に応じて選べる設計です。「テルナリ」とは「3つの値を使う」という意味の英語です。（出典：Medium / LLM Configurator・2026年7月）
  • ② 圧縮しても「賢さ」が落ちすぎない工夫
    ただ圧縮するだけでは精度が大幅に落ちてしまいます。PrismMLは元のQwen3.6 27Bの「知識」をできるだけ保持しながら量子化する独自の手法を開発しました。その結果、テルナリ版では元のフル精度モデルの94.6%の性能を維持したとしています（公式申告値）。（出典：LLM Configurator / Medium・2026年7月）
  • ③ スマホのNPU（AIチップ）を活用
    現代のスマートフォンには「NPU（ニューラル・プロセッシング・ユニット）」というAI処理専用チップが搭載されています。Bonsai 27Bはこのチップを最大限に使うよう最適化されており、CPU・GPUだけに頼らず省電力で動作するよう設計されています。「量子化」との組み合わせで、スマートフォンという制限された環境でも実用的な速度を実現しています。（出典：Decrypt / Layer3Labs・2026年7月）

性能は落ちる？
── 94.6%を維持・秒11トークンで動作
性能・影響・注意点
🌱 やさしく解説
スマホで動く便利さと引き換えに性能が大きく落ちてしまうなら意味がありません。PrismMLの発表によると、Bonsai 27B（テルナリ版）は元のフル精度モデルの94.6%の性能を維持しているとされています。また、iPhone 17 Pro系の端末では1秒間に11トークン（単語やひとかたまりの文字）を生成できるとしています。これは短い文なら数秒、長めの文でも十数秒で返答が出てくる速さです。（出典：Medium / LLM Configurator・2026年7月）

  • ○ 実用上の速さ ── 「秒11トークン」はどのくらい？
    日本語の1文（15〜20文字程度）はだいたい10〜15トークン前後に相当します。つまり短い文なら約1秒、中程度の回答（100〜200文字）なら10〜20秒ほどで生成できる計算になります。これはクラウド型AIの応答速度には及ばないものの、オフラインで動く実用的なスピードとして評価されています。（出典：Medium / Developers Digest・2026年7月）
  • △ 注意点：性能数値はPrismML自身の計測
    「94.6%の性能維持」「秒11トークン」という数値は、いずれもPrismMLが自ら測定・発表したものです。2026年8月時点では独立した研究者による第三者検証は限られており、実際の体験はモデルの用途・言語・端末の発熱状況によって異なる可能性があります。実際に使う前に自分でテストすることをおすすめします。（出典：Medium・2026年7月）
  • ▶ 業界への波及 ── Appleとの交渉報道（要確認）
    米CNBC は「Appleがこの圧縮技術についてPrismMLと初期段階の交渉をしている」と報道しています（2026年7月）。ただしこの提携交渉は公式発表がなく、詳細・時期・条件は公式で要確認です。一方、オンデバイスAI（端末上で動くAI）の流れは業界全体で進んでおり、スマホで高品質なAIが動く時代が近づいています。（出典：CNBC 報道・2026年7月 ／ 詳細は公式で要確認）
