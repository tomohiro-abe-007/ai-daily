何が起きた？ ── Salesforce が「Slack Code」を発表
AIコーディング

2026年8月（メディア報道は8月20〜21日、Salesforce公式プレスリリースは8月24日）、 Salesforceが「Slack Code（スラック・コード）」を発表しました。 これは、ビジネスチャットツール「Slack（スラック）」の中に AIがコードを書いてくれる「コードチャンネル」を新設する機能です。

ことばの整理
Slack（スラック）：仕事で使うチャット・コミュニケーションアプリです。 メッセージを送ったり、ファイルを共有したりできます。Salesforce（セールスフォース）が運営しています。

AIエージェント：人間から「〇〇を作って」と指示を受けて、自分でコードを書いたり、 調べたり、修正したりを自動でこなすAIのことです。単に質問に答えるだけでなく、「作業をする」AIです。

これまでAIがコードを書く作業は、エンジニア1人が自分のパソコンの中でこっそり作業するものでした。 Slack Code は「チーム全員がリアルタイムでAIの作業を見たり・止めたり・指示したりできる」 仕組みを提供します。Salesforceは「AIコーディングをマルチプレイヤー（多人数参加型）にする」と表現しています。

📌 スポーツで例えると：今まではAIが「1人でこっそり素振りする」感じでしたが、 Slack Code は「チーム全員がグラウンドでAIのバッティングを見て、アドバイスできる」イメージです。
出典：Salesforce公式プレスリリース「Salesforce Launches Slack Code to Make AI Software Development Multiplayer」（2026年8月24日）／ VentureBeat「Slack wants to drag AI coding out of the terminal and into the group chat」（2026年8月）
⚙️
Slack Code の仕組み ── 4つのタブと対応AIエージェント
仕組みを知る

Slack Code では、専用の「コードチャンネル」を作ると、チャット画面が 4つのタブに分かれます。 AIが何をしているかを、誰でもリアルタイムで確認できます。

💬 ① 会話タブ チームとAIがやり取りするチャット画面。指示・質問・フィードバックをここで行う
📋 ② 計画タブ AIがどんな手順で作業するかを一覧表示。「次に何をするか」が事前にわかる
🔍 ③ 差分タブ AIが書いたコードの「変更点」を行ごとに確認できる。何を変えたか一目瞭然
▶️ ④ プレビュータブ AIが作ったアプリやページが実際に動く様子をリアルタイムで確認できる

Slack Code に対応しているAIエージェントは、2026年8月時点で以下の通りです （今後も追加予定と発表されています）。

🤖 Claude Code Anthropic
🧠 Devin Cognition
🐙 GitHub Copilot Microsoft
💬 ChatGPT エージェント OpenAI
▲ Vercel エージェント Vercel
対応プランは？
Slack Code はSlackの全プランで利用可能と発表されています。 ただし、各AIエージェントを使うには、それぞれのサービスへの契約・API設定が別途必要な場合があります。 詳細は Salesforce/Slack 公式サイトでご確認ください。
出典：Slack公式ブログ「Slack Code: Where Your Team and Agents Build Together」（2026年8月）／ The Next Web「Slack launches Slack Code, where teams and AI agents build together」（2026年8月）

何が変わる？ ── AIコーディングが「チームで見える・止められる」
変化のポイント

Slack Code の最大の特徴は、AIの作業を チーム全員がリアルタイムで「見て・触れる」ようにしたことです。

🔒 これまでのAIコーディング
・エンジニア1人が自分のパソコンで作業
・他のメンバーは「結果」しか見られない
・途中でAIを止めるのが難しい
・「何を変えたか」の確認が後回し

→ AIが「ブラックボックス」になりがち
✅ Slack Code でできること
・チャンネルの誰でも作業をリアルタイムで確認
・途中でAIを一時停止・方向転換できる
・コードの変更点を行単位で確認できる
・本番環境への適用は人間の承認が必須

→ AIの作業が「ガラス張り」になる
  • ① 「止める」権限は全員が持つ：チャンネルに参加しているメンバーは誰でも AIの作業を一時停止したり、方向を変える指示を出したりできます。 「エンジニアだけが操作できる」のではなく、デザイナーや企画担当者も関われます。 （出典：Salesforce公式プレスリリース・2026年8月24日）
  • ② 「本番適用は人間がGOサイン」：AIが書いたコードが完成しても、 実際のシステムに反映（本番プッシュ）するには人間の最終承認が必要です。 AIが「勝手に本番を書き換える」ことはできない仕組みになっています。 （出典：Dataconomy・2026年8月21日）
  • ③ 「バラバラなタブ問題」を解決：これまでのAIコーディングは 「コードエディタ」「チャット」「ブラウザプレビュー」がバラバラのウィンドウで開いており管理が大変でした。 Slack Code ではこれを1つのチャンネル内にまとめ、チームで共有できます。 （出典：The Next Web・2026年8月）
📌 たとえ話：今まではシェフ（AIエージェント）が厨房（個人PC）で1人で料理を作り、 出来上がったものをテーブルに持ってくるだけでした。 Slack Code は厨房をガラス張りにして、テーブルの全員が 「もっと辛くして」「そっちの食材じゃなくて」と声をかけられるイメージです。
出典：Dataconomy「Slack Launches Code For AI Coding Collaboration」（2026年8月21日）／ AIN.UA「Slack introduced Slack Code channels for working with AI agents」（2026年8月20日）

なぜ大事か？ ── 開発の「民主化」と残る課題
社会的背景・展望

Slack Code の登場は「誰がソフトウェアを作るか」という問いに大きな変化をもたらす可能性があります。 コードを書けない人でも、AIに指示を出してアプリを作れる時代が チームのコミュニケーションツールの中で本格化し始めました。

  • A 「非エンジニア」でも開発に参加しやすくなる：デザイナー・営業担当・マーケターなど コードを書かないメンバーも、Slackのチャット感覚でAIに「こんなボタンを追加して」などと 指示を出せます。ソフトウェア開発が「エンジニア専用作業」から変わりつつあります。
  • B AIツールの「乱立」が整理される可能性：Claude Code・GitHub Copilot・Devinなど 複数のAIエージェントを1つのSlackチャンネルから切り替えて使えることで、 「どのAIが得意か」を比較・使い分けしやすくなります。
  • C セキュリティ面の課題も：一方で、チャットツールの中でコードが動くことで 「誰でも操作できる」「誤った指示で重大バグが生まれる」リスクも指摘されています。 権限管理や操作ログの確認など、企業ごとのルール整備が重要になります。
⚠️ 注意：AI生成コードのリスクは変わらない
AIがコードを書いてくれても、バグや脆弱性（セキュリティの穴）が混入するリスクは存在します。 Slack Code があっても「コードレビュー（人間によるチェック）」は引き続き欠かせません。 「AIが作った＝安全」とは限らないことを意識しておきましょう。
✅ Slack Code が示していること
AIコーディングの波は「1人のエンジニアの作業効率化」を超え、 「チーム全体の開発のあり方を変える」フェーズに入りつつあります。 Slackというすでに多くの企業が使うチャットツールに組み込まれることで、 AIコーディングが「特別な人のツール」から「仕事の標準ツール」へと変わる可能性があります。
出典：TechBriefly「Slack launches Code for AI coding agents」（2026年8月21日）／ iTechPost「Slack Code Launches Collaborative AI Coding Channels for Vibe Coding」（2026年8月21日）
