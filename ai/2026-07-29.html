FLUX 3 って何？
── 「マルチモーダル生成AI」の新しいかたち
新モデル発表
🌱 やさしく解説
2026年7月23日、ドイツのAIスタートアップ「Black Forest Labs（ブラック・フォレスト・ラブズ、略称：BFL）」が「FLUX 3（フラックス・スリー）」を発表しました。FLUX はもともと高品質な「画像生成AI」として知られていましたが、FLUX 3 では一気に進化して画像・動画・音声・さらにはロボットの動き制御まで、すべてを「同じひとつのAI」で行えるようになりました。（出典：GlobeNewswire / Black Forest Labs 公式プレスリリース・2026年7月23日）
  • ① 「Black Forest Labs」って何者？── 画像生成AIの世界的なスタートアップ
    Black Forest Labs はドイツを拠点とするAIスタートアップで、画像生成AI「FLUX.1」シリーズを開発してきた会社です。FLUX.1 は高解像度・高品質な画像生成で多くのクリエイターやデザイナーに利用されてきました。FLUX 3 はその次世代版にあたります。（出典：GlobeNewswire・2026年7月23日 / VentureBeat・2026年7月23日）
  • ② 「マルチモーダル（multimodal）」とは？── 複数の種類を扱えるAI
    「マルチモーダル」とは「複数の種類（モダリティ）のデータを扱える」という意味です。たとえば「テキストだけ」「画像だけ」が扱えるAIは「シングルモーダル」。一方 FLUX 3 は画像・動画・音声・ロボット動作という4種類の出力を、ひとつのモデルの重み（設定値）で生成します。これがこれまでの生成AIと大きく異なる点です。（出典：MarkTechPost・2026年7月26日 / digitalapplied.com・2026年7月23日）
  • ③ なぜ「ひとつのモデル」で扱えることが画期的なのか
    これまで「画像生成AI」「動画生成AI」「音声生成AI」はそれぞれ別々のモデルでした。FLUX 3 では同じ設定値（重み）でこれらすべてを生成できるため、モデル同士が「お互いの情報を活かし合う」ことができます。たとえば動画を生成するときに「画像の知識」も活用するので、品質や一貫性が向上します。（出典：wan27.org・2026年7月 / artiverse.ca・2026年7月23日）
✏️ 中学生的に言うと：「絵を描くAI会社が、絵・動画・音・ロボット動作をまとめて担当できる超万能AIを作った。別々のAIが必要だったのを、ひとつでまとめてやってのけた。」
📎 出典： GlobeNewswire – "Black Forest Labs Unveils FLUX 3"（2026年7月23日） / VentureBeat – "Black Forest Labs launches FLUX 3"（2026年7月23日） / MarkTechPost – "FLUX 3: A Multimodal Flow Model"（2026年7月26日）

何ができる？
── 動画・音声・ロボットまで1つのモデルで
機能紹介
🌱 やさしく解説
FLUX 3 には大きく4つの能力があります。画像生成・編集（FLUX 3 Image）、最長20秒の動画生成（FLUX 3 Video）、動画に同期した音声の自動生成、そしてロボットの動作制御（FLUX 3 Action）です。特に「動画と音声を同時生成」する点が注目されています。（出典：GlobeNewswire・2026年7月23日 / TechTimes・2026年7月25日）
  • ① FLUX 3 Video── 最長20秒の動画を音声つきで一気に生成
    FLUX 3 Video は最長20秒の動画を1回の生成で作成できます。ほかの動画AIでは複数のクリップをつなぎ合わせて長い動画を作るケースが多いですが、FLUX 3 はつなぎ合わせなし（ネイティブ生成）で20秒を一発生成します。さらに音声も動画と一緒に同時生成されます。物が落ちる音、会話の口の動き、環境音などが映像に自動的に同期します。（出典：VentureBeat・2026年7月23日 / explainx.ai・2026年7月）
  • ② 音声と映像の「自然なズレのなさ」── なぜ重要か
    音と映像がズレているとすぐに不自然に感じます。FLUX 3 は音声と映像を同じ1つのモデルで同時生成するため、「音と映像が自然に合っている」状態が生まれやすい設計です。たとえばボールが床に当たる瞬間にちょうど「ドン」という音が鳴る、セリフを話しているとき口の動きと音声が合っている、といった精度が向上するとされています。（出典：wan27.org・2026年7月 / digitalapplied.com・2026年7月23日）
  • ③ FLUX 3 Action── ロボットに「動き方」を教えるAI
    FLUX 3 はロボットの動作制御にも対応します。「FLUX 3 Action（アクション）」と呼ばれるこの機能では、画像や動画を見てロボットが次に取るべき動き（アクション）を予測・生成します。工場や倉庫でのロボット操作など「物理世界で動くAI」への応用が期待されています。（出典：MarkTechPost・2026年7月26日 / TechTimes・2026年7月25日）

⚙️
裏側の技術
── 「Self-Flow」とは何か
技術解説
🌱 やさしく解説
FLUX 3 の基盤となっている技術は「Self-Flow（セルフ・フロー）」と呼ばれる手法で、Black Forest Labs が2026年3月に発表しました。一言でいうと「生成の上手さ」と「理解の上手さ」を同時に鍛えるトレーニング方法です。この方法のおかげで、ひとつのモデルが複数の種類のデータを高品質に扱えるようになりました。（出典：MarkTechPost・2026年7月26日 / explainx.ai・2026年7月）
  • ① 「フロー・マッチング（flow matching）」── ノイズを除いて綺麗な画像を作る仕組み
    AIで画像や動画を生成するとき、よく使われる方法が「ランダムなノイズ（ざらつき）から少しずつ綺麗な画像に近づける」というものです。「フロー・マッチング」はこのノイズ除去の過程を数学的に最適化する手法のひとつで、生成品質を高める効果があります。FLUX シリーズはもともとこの技術を採用していました。（出典：MarkTechPost・2026年7月26日）
  • ② 「自己教師あり学習（self-supervised）」── 答えなしで学ぶ仕組みを追加
    Self-Flow のもうひとつの特徴が「自己教師あり特徴の再構成」という仕組みです。これは人間が「正解」を教えなくても、AIが自分自身の別の部分（教師モデル）から学習する方法です。わかりやすく言うと「先輩役のAI（EMAティーチャー）が生徒役のAIに教える形で、自動的に賢くなる」仕組みです。この先輩役と生徒役は同じモデルの別の層（レイヤー）が担当します。（出典：MarkTechPost・2026年7月26日）
  • ③ 「生成も理解も上手くなる」── 両方を同時に改善できる点が特徴
    従来の生成AIは「生成が上手くなると理解が下がる」というジレンマがありました。Self-Flow は「生成の品質（FD スコア）」と「ロボット制御の成功率」を両方同時に向上させることが実験で確認されています。これが「画像も動画もロボット動作もひとつのモデルで扱える」ことを可能にした技術的な根拠です。（出典：MarkTechPost・2026年7月26日 / explainx.ai・2026年7月）
🔵 Self-Flow の2つの柱
① フロー・マッチング
　→ ノイズから高品質なコンテンツを生成する
② 自己教師あり特徴再構成
　→ AIが自分で自分に教えて「理解力」も高める
（出典：MarkTechPost・2026年7月26日）
🟢 何が改善された？
・動画の生成品質（FD スコアで測定）
・ロボット制御のシミュレーション成功率
→ 「作る」と「理解する」を両立
（出典：MarkTechPost・2026年7月26日）
✏️ 中学生的に言うと：「先輩AIが後輩AIに教えながら、同時に作る力も理解する力も鍛える仕組み。これのおかげで画像・動画・音声・ロボット全部をひとつのAIで担当できるようになった。」
📎 出典： MarkTechPost – "FLUX 3: A Multimodal Flow Model for Image, Video, Audio and Robot Action Prediction"（2026年7月26日）

今どこまで使える？
── 現在の公開状況
リリース状況
🌱 やさしく解説
2026年7月29日時点では、FLUX 3 のすべての機能がまだ一般公開されているわけではありません。一部の機能はパートナー企業向けの「限定アーリーアクセス（ゲーテッド公開）」の段階です。一般向けに広く使えるようになるには、もう少し時間がかかる見通しです。（出典：VentureBeat・2026年7月23日 / TechTimes・2026年7月25日）
  • ① FLUX 3 Video・FLUX 3 Action── 限定パートナー向けにアーリーアクセス開始
    「FLUX 3 Video」と「FLUX 3 Action」は2026年7月23日時点で、選ばれたパートナー企業への限定提供が始まりました。これは一般ユーザーがすぐに試せる状態ではなく、まずは特定の企業が試験的に使う段階です。（出典：VentureBeat・2026年7月23日）
  • ② FLUX 3 Image── 数週間後に公開予定
    画像生成を担う「FLUX 3 Image」は発表時点では未公開で、「数週間以内に続いて公開予定」と案内されています。時期・提供方法の詳細は公式サイトで要確認です。（出典：VentureBeat・2026年7月23日）
  • ③ FLUX 3 Dev（オープンウェイト版）── 2026年内の公開を予定
    「Dev（デブ）」と名付けられたオープンウェイト（誰でも中身にアクセスできる形式）の公開版は、2026年後半に提供予定と発表されています。オープンウェイト版が出ると、研究者や開発者が自分でモデルを動かしたり、改造したりできるようになります。時期は未確定のため、公式情報を確認してください。（出典：VentureBeat・2026年7月23日 / artiverse.ca・2026年7月23日）

📝 今日のまとめ ── FLUX 3 発表（2026年7月23日）

🎯
4種類を1つのAIで
Black Forest Labs の FLUX 3 は画像・動画（最長20秒）・音声・ロボット動作制御を、ひとつのモデルの重みで生成する初の本格的マルチモーダル生成AI。
🔊
音声と映像を同時生成
動画と音声をひとつのパスで一緒に作るため、物音・会話・環境音が映像に自然に同期する。別々に生成してつなぐ方法より精度が高い設計。
⚙️
Self-Flow 技術が基盤
2026年3月発表の「Self-Flow」が支える。フロー・マッチングと自己教師あり学習を組み合わせ、生成品質と理解力を同時に向上させた。
🔑
まだ限定公開の段階
FLUX 3 Video・Action はパートナー向け限定アクセス中。FLUX 3 Image は数週間内、オープンウェイト版「Dev」は2026年内を予定。詳細は公式で要確認。
