何が起きた？
── セキュリティ事件のあらすじ（2026年6〜8月）
セキュリティ
🌱 やさしく解説
2026年6月、有名なクラウドサービス企業「Snowflake（スノーフレーク）」のプログラムに危ない穴（脆弱性＝ぜいじゃくせい）が見つかりました。その穴を見つけたのは、なんと人間のセキュリティ専門家ではなく「AI製のセキュリティ調査ロボット」でした。しかもその穴は、コードを自動修正する別のAI「GitHub Copilot Autofix（コパイロット・オートフィックス）」が共同作成したコードに含まれていたと報告されています。この一連の出来事が2026年8月に広く報じられました。（出典：Forbes・2026年8月17日 / SC Media・2026年8月）
  • ① 「Snowflake（スノーフレーク）」とは？
    Snowflakeはアメリカの大手クラウドデータ企業です。多くの企業がデータ保管・分析に使っており、そのコードはGitHub（ギットハブ）というプログラム共有サービスで公開されています。今回の問題はこの公開リポジトリ（ファイル置き場）で起きました。（出典：Wiz Blog・2026年8月）
  • ② 「GitHub Copilot Autofix（コパイロット・オートフィックス）」とは？
    GitHub Copilot Autofixは「コードの問題を自動で見つけて修正する」AIツールです。プログラマーが書いたコードに潜むバグやセキュリティの問題を検知して、修正案を提案・適用します。本来は「安全なコードを作るためのAI」ですが、今回はその共著コードに穴が残っていたと指摘されました。
  • ③ 事件のタイムライン
    問題のコードは2026年6月18日にSnowflakeの主要ブランチ（公開版）に取り込まれました。その5日後の6月23日、クラウドセキュリティ企業Wiz（ウィズ）のAIエージェント「Red Agent（レッド・エージェント）」が脆弱性を発見し、同日中に報告。Snowflakeは同日に修正し、認証情報もすぐに無効化しました。（出典：Wiz Blog / SC Media・2026年8月）
✏️ 中学生的に言うと：「コードを自動修正するAIが作ったプログラムに危ない穴があり、別のAI調査員がそれを5日で発見。同日中に直された。この一連の出来事が2026年8月に注目を集めた。」
📎 出典： Forbes – "GitHub Copilot Missed A Vulnerability That Wiz's AI Agent Found"（2026年8月17日） / SC Media – "Wiz agent finds Snowflake repo flaw in code co-authored by GitHub Copilot Autofix"（2026年8月）
🕳️
脆弱性の仕組み
── 「イシューを開いたら情報が盗まれる」
技術解説
🌱 やさしく解説
今回の問題は「スクリプトインジェクション（script injection）＝命令の割り込み」という種類の攻撃でした。GitHubに「Issue（イシュー）＝質問・バグ報告のスレッド」を書き込める人なら誰でも、巧みなタイトルを書くだけでSnowflakeの内部システムへのパスワード（Jira APIトークン）を盗める状態でした。（出典：Cyber Kendra・2026年8月 / The Hacker News・2026年8月）
1
問題のファイル：.github/workflows/jira_issue.yml
Snowflakeのリポジトリには「GitHubにIssueが投稿されたら、自動でJira（社内タスク管理ツール）にチケットを作る」自動化スクリプトが入っていました。
↓
2
穴の場所：Issue（イシュー）のタイトルがそのままコマンドに渡されていた
タイトルを「シングルクォート（'）などの特殊文字を含む文字列」にすると、コマンドから脱出して任意の命令を実行できる状態でした。これを「コマンドインジェクション」と言います。
↓
3
攻撃の結果：認証情報が丸ごと漏れる
悪用されると JIRA_API_TOKEN（Jiraへのパスワード）などが盗まれ、社内のJiraシステムに不正アクセスされる可能性がありました。Wiz社の調査では、実際に被害は発生していないことが確認されています。（出典：Cyber Kendra・2026年8月）
↓
✓
修正完了：Wiz報告の同日（2026年6月23日）に Snowflake がパッチ適用・認証情報を無効化。被害はゼロ確認済み。
✏️ 中学生的に言うと：「質問スレッドのタイトルに特殊文字を入れるだけで、会社のパスワードが盗まれる状態だった。Wiz AIが見つけてすぐ直り、実害ゼロ。」
📎 出典： Cyber Kendra – "Copilot Autofix Bug Exposed Snowflake's Internal Jira"（2026年8月） / The Hacker News – "Snowflake GitHub Actions Flaw Lets Crafted Issues Trigger Command Injection"（2026年8月）

AIがAIのミスを発見
── Wiz「Red Agent」の登場
AIエージェント
🌱 やさしく解説
脆弱性を発見したのは、クラウドセキュリティ企業Wiz（ウィズ）が開発した「Red Agent（レッド・エージェント）」というAIです。「レッドチーム（red team）＝攻撃する側になって弱点を探すテスト役」をAIが担う仕組みです。今回の事件は「セキュリティを高めるはずのAIが作ったコードの穴を、セキュリティを守るAIが見つけた」という、AIどうしが絡み合う珍しい構図になりました。（出典：Wiz Blog・2026年8月 / Forbes・2026年8月17日）
  • ① 「Red Agent（レッド・エージェント）」とは？
    Wizが開発したAIセキュリティエージェントです。公開されているGitHubリポジトリを自律的に調べ、脆弱性を探すことができます。人間のセキュリティ研究者が行うような「コードを読んで怪しい部分を見つける」作業をAIが代行します。（出典：Wiz Blog・2026年8月）
  • ② 「Copilot Autofixが共著」の意味
    GitHubでは、AIがコードの修正に関わった場合「Co-authored by Copilot Autofix」という記録が残ります。問題のコミット（変更記録）にはこの記録が含まれており、Wiz社は「AIが安全修正をした際に危険なコードも混入した」と主張しました。（出典：SC Media / Cyber Kendra・2026年8月）
  • ③ なぜ5日で見つかった？
    Red AgentはSnowflakeのリポジトリを調査対象として選び、GitHub Actionsワークフロー（自動処理の設定ファイル）の中にユーザー入力が適切に処理されていない箇所を見つけました。発見から報告、修正完了までわずか数時間という、人間チームだけでは難しいスピードでした。（出典：Forbes・2026年8月17日）
✏️ 中学生的に言うと：「『コードを直すAI』が作ったプログラムに穴があり、それを『穴を探すAI』が数日で発見。AIが増えた世界では、AIをAIでチェックする時代になってきている。」
📎 出典： Wiz Blog – "Red Agent Exploits Snowflake Vuln Missed by Github Copilot"（2026年8月） / Forbes – "GitHub Copilot Missed A Vulnerability That Wiz's AI Agent Found"（2026年8月17日）
⚖️
争点：「本当にAIが書いたの？」
── GitHubとWizの食い違い
議論・論点
🌱 やさしく解説
Wiz社は「GitHub Copilot Autofixが共著したコードに穴があった」と発表しましたが、GitHubは「脆弱性を引き起こしたコードを書いたのは人間のエンジニア。Copilotは関係ない」と否定しています。AIのせいにするのか、人間のせいにするのか。AIが増えるほどこの「責任の所在」の問題は難しくなります。（出典：The Next Web・2026年8月）
  • ① Wizの主張
    2026年6月18日に取り込まれたコードの変更記録には「Co-authored by Copilot Autofix」の記録があり、そのコードが脆弱性を含んでいた。AIがセキュリティ修正をした際に、誤って危険なコードも作ってしまったと主張。（出典：Wiz Blog / Cyber Kendra・2026年8月）
  • ② GitHubの反論
    GitHubは内部調査の結果として「脆弱性のある変更は人間のエンジニアが書いたものであり、Copilot Autofixが書いたコードではない」と発表しました。Copilotが共著した箇所は別の変更であると主張しています。（出典：The Next Web・2026年8月）
  • ③ なぜこの議論が重要なのか？
    AIが書いたコードが増えるほど、「バグや事故の責任は誰にあるのか」が曖昧になります。AIツール提供企業なのか、AIの出力をそのまま使った開発者なのか。これは法律・保険・品質保証など幅広い分野で今後議論が続く問題です。今回のWizとGitHubの食い違いは、その難しさを象徴する出来事と言えます。（出典：Forbes・2026年8月17日 / The Next Web・2026年8月）
⚠️ 今の時点で確認できていること
・脆弱性が存在したこと、Wiz社が2026年6月23日に発見・報告したこと、Snowflakeが同日修正・認証情報を無効化したことは確認済み。
・「Copilot Autofixが脆弱なコードを書いた」か「人間が書いた」かは現時点（2026年8月）で両社の主張が食い違っており、決着していない。
・Wiz社の調査では、公開されていた間に実際に悪用された形跡はないとのこと。
✏️ 中学生的に言うと：「AIが書いたコードに問題があった、とWizは言う。GitHubは人間が書いたと反論。どちらが正しいかは未決定。でも『AIが書いたコードの責任は誰のもの？』という問いは、これから本当に大事になる。」
