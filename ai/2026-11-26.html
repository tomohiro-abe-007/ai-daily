AIが書いたプログラムを、AIのチームがチェック？
Claude Code の「Code Review」をやさしく解説

2026-11-26
📋どんな話？解説
今日のトピック
Anthropic（アンソロピック）は2026年3月9日付の公式記事で、「Code Review（コードレビュー）」を紹介しました。レビューとは、書かれたプログラムに間違い（バグ）がないか、ほかの人が見てチェックする作業です。
💡 AIがプログラムをたくさん書くようになると、チェックする人の手が足りなくなります。そこで「チェックもAIに手伝わせよう」という考え方です。
お知らせ
今日は直近1週間の新しい出来事を検索で確認できなかったため、公式ページで内容を確認できた話題を取り上げています。
出典（2026年3月）：Anthropic公式ブログ
⚙️どうやって動くの？しくみ
  • 1変更案（プルリクエスト＝「この変更を取り込んでください」という依頼）が出されると、複数のAIエージェント（自分で考えて動くAI）のチームが動きます。
  • 2チームは並行してバグを探し、見つけたものが本当かを確かめて（まちがい報告を減らして）、重要度順に並べます。
  • 3結果は、全体のまとめコメント1つと、場所ごとのコメントで表示されます。小さな変更は軽く、大きな変更は深く調べます。
  • 4AIは変更を承認（OKを出す）しません。最終判断は人間です。
出典（2026年3月）：Anthropic公式ブログ
📊数字と注意点ポイント
  • 1Anthropic社内では、意味のあるコメントがつく変更が16%から54%に増えたと説明されています（自社の数字）。
  • 2見つかった指摘のうち、エンジニアが「まちがい」とした割合は1%未満とのことです（自社の数字）。
  • 31回の確認は平均およそ20分、費用は目安で15〜25ドルと書かれています。軽い別ツールより高く、遅めです。
  • 4公開当初は、TeamとEnterpriseプラン向けの研究プレビュー（お試し段階）でした。記事には、のちに一般提供になったとの追記があります。

Code Reviewは、AIのチームがプログラムの変更を並行してチェックし、バグの候補を重要度順に教えてくれる機能です。承認は人間が行います。料金や提供範囲は公式で確かめましょう。
