手描きスケッチが AI 画像に── 画像生成モデルが大幅進化
「描いて→変える→整える」がずっとスムーズになった（2026年9月）

2026-09-18
📋 このスライドの内容 新モデル
今日のトピック
2026年9月8日、OpenAI が 「ChatGPT Images 2.5（画像生成モデルの新バージョン）」 を発表した。 前バージョン（Images 2.0）と比べて画像の生成速度が最大 50% 向上し、 手描きのスケッチを AI 画像に変換する「Sketch（スケッチ）機能」も新搭載。 参照写真の人物や物をより正確に保持したまま編集できるようになり、 複数回の指示にも一貫して対応できるようになった。 開発者向けには速度重視の「Flare」と高精細の「Sunburst」という 2 つの API モデルが同時に公開された （出典：OpenAI 公式 / Unite.AI / Pexo・2026年9月）。
  • 1 Sketch（スケッチ）機能が新登場： 紙に描いた落書きや手描き図をアップロードして AI 画像に変換できる。 「こんな感じのイメージ」を伝えるのが簡単になった
  • 2 生成速度が最大 50% 向上（Images 2.0 比）： 待ち時間が半分になる場合もある。速さを重視した API モデル Flare で特に効果的
  • 3 編集の一貫性・精度が向上： 「背景だけ変えて」「色だけ変えて」といった指示を複数回繰り返しても、 変えたくない部分が崩れにくくなった
✏️ 新機能「Sketch」── 手描きが AI 画像になる 新機能

  • ▶ テキストだけでは伝えにくいアイデアを 視覚で直接指定できるのが最大の利点

🔧 開発者向け API── 2 つのモデルを選べる API

ChatGPT Images 2.5 では、開発者（アプリやサービスを作る人）向けに 2 種類の API モデルが用意された。 用途に合わせて使い分けられる。

⚡ GPT-Image-2.5 Flare（フレア）
速度優先
素早く生成したいケース向け。ある程度の品質を保ちつつ、とにかく速く出力したい用途に最適
✨ GPT-Image-2.5 Sunburst（サンバースト）
精細度優先
より詳細・高品質な画像が必要なケース向け。時間はかかるが、細かい表現が求められる用途に
利用できる場所
・ChatGPT（一般ユーザー向けチャットサービス）
・ChatGPT Work（企業・チーム向けプラン）
・Codex（プログラミング支援ツール）
※ API 料金・詳細な利用条件は OpenAI 公式サイトで要確認
📝 用語をやさしく解説 用語
  • 語 画像生成 AI ── テキスト（文章）や参照画像を入力すると、新しい画像を作り出す AI。「青い空の下で走る犬を描いて」と入力すると数秒で画像が完成する
  • 語 Sketch（スケッチ）機能 ── 手描きの絵やラフな図をアップロードして AI への指示として使える機能。細かく描かなくても形や配置を伝えられる
  • 語 API（エーピーアイ） ── 開発者が自分のアプリやサービスに AI の機能を組み込むための「接続窓口」。API を使うと自作アプリから ChatGPT の画像生成を呼び出せる
  • 語 レイテンシ（Latency） ── リクエストを送ってから結果が返ってくるまでの「待ち時間」。レイテンシが低い（小さい）ほど、素早く結果が出る
  • 語 参照写真（Reference Photo） ── 「この人物・この物をベースに画像を作って」と AI に渡す元の写真のこと。AI が参照写真の特徴をできる限り保ちながら新しい画像を生成する

📌 ひとことまとめ

2026年9月8日、OpenAI が 「ChatGPT Images 2.5」を発表した。 目玉は手描きスケッチを AI 画像に変換する「Sketch 機能」と、 生成速度の最大 50% 向上（前バージョン比）の 2 点。 参照写真の被写体をより正確に保ちながら編集できるようになり、 複数回にわたる指示でも一貫した出力が得られるようになった。 開発者向けには速度優先の「Flare」と高精細の「Sunburst」という 2 種類の API モデルが用意され、用途に応じて選べる。 料金・詳細仕様は公式サイトで要確認。
