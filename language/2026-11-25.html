🔢序数ってなに?1〜10を覚えるしくみ

序数(じょすう=「1番目・2番目」のように順番を表す数)は、ふつうの数(uno, dos, tres…)とは別の単語です。毎日よく使うのは1〜10までなので、まずここだけ覚えれば十分です。

uno → primero
segundo

dos → segundo
tercero
3番目
tres → tercero
cuarto
4番目
quinto
5番目
sexto
6番目
séptimo
7番目
octavo
8番目
noveno
9番目
décimo
10番目
💡 英語を知っていると覚えやすい
segundo は英語の second、octavo は音楽の「オクターブ」(8つ目の音)、décimo は decimal(10進法)と同じ仲間。英語→スペイン語の順で学ぶと、つづりから意味が想像できます。
参考:RAE: Tabla de numerales / SpanishDict: Ordinal Numbers in Spanish
🎎女性形・複数形にも変わる新しい知識

序数は形容詞(名詞を説明する言葉)の仲間なので、後ろの名詞に合わせて-o / -a / -os / -as と語尾が変わります。ふつうの数(dos, tres)は変わらないので、ここが大きな違いです。

形例意味
男性・単数 -oel segundo día2日目
女性・単数 -ala segunda calle2本目の通り
男性・複数 -oslos primeros días最初の何日か
女性・複数 -aslas primeras semanas最初の何週間か
数字で書くと
男性形は 1.º 2.º、女性形は 1.ª 2.ª(右上の小さな o / a が語尾のしるし)。11-18 で見た住所の「3.º 2.ª」は tercero, segunda(3階の2号室)と読みます。
参考:RAE: DPD「ordinales」 / RAE: Ortografía de los numerales ordinales
✂️primer・tercer:語尾が消えるルールテクニック

primero と tercero の2つだけ、男性・単数の名詞の前に来ると最後の -o が消えます。これを語尾脱落(ごびだつらく=単語のおしりが落ちること)と言います。

👨 男性名詞の前
el primer piso(×el primero piso)/ el tercer día
👩 女性名詞の前
消えない:la primera vez / la tercera planta(×la tercer vez)
🔚 名詞の後ろ・単独
消えない:el piso primero / Soy el primero.(私が1番です)
➕ 間に形容詞
男性名詞が後に続くなら消える:el primer gran paso(最初の大きな一歩)
⚠️ 女性形には付けない
「la tercer vez」のような言い方は、RAE(スペイン王立アカデミー=スペイン語の基準を作る機関)が古い言い方としていて、今は la tercera vez がすすめられる形です。
💡 bueno → buen と同じ仲間
un buen día(×un bueno día)、algún、ningún も同じ「男性単数の前で -o が落ちる」グループ。primer / tercer をこのグループとまとめて覚えると楽です。数字で書くときは 1.er / 3.er と書けます。
参考:RAE: DPD「primero」 / RAE: DPD「ordinales」 / RAE: Los ordinales
🌉英語とくらべる:first, second, third英語→スペイン語

英語の序数は形が変わらず、数字で書くときは 1st 2nd 3rd 4th と最後の2文字を付けます。スペイン語は 1.º / 1.ª と、男性・女性で書き分けるのが違いです。

🇬🇧⇄🇪🇸 序数 対応表
日本語英語スペイン語
1番目first(1st)primero / primera(1.º / 1.ª)
2番目second(2nd)segundo / segunda(2.º / 2.ª)
3番目third(3rd)tercero / tercera(3.º / 3.ª)
初めてfor the first timepor primera vez
右の2本目the second street on the rightla segunda calle a la derecha
やさしく言うと
英語は「1st」を覚えれば形は1つ。スペイン語は「名詞が男か女か」で primero / primera を選ぶ、とだけ覚えておきましょう。
参考:Cambridge Dictionary「ordinal number」 / SpanishDict: Ordinal Numbers in Spanish
🏢スペインの階数:primer piso は日本の2階注意

スペインでは、地面と同じ高さの階を planta baja(プランタ・バハ=地上階)と呼び、その1つ上から primer piso(1階)と数えます。日本の数え方と1つずれるので要注意です。

B
planta baja(PB / 0)= 日本の1階
⬆️
1
primer piso / primera planta(1.º)= 日本の2階
⬆️
2
segundo piso / segunda planta(2.º)= 日本の3階
🇬🇧🇺🇸 英語でも同じずれがある
イギリス英語は ground floor(地上階)→ first floor(日本の2階)で、スペインと同じ数え方。アメリカ英語は first floor = 地上階で、日本と同じです。
⚠️ エレベーターのボタンを確かめる
建物によっては planta baja と primer piso の間に entresuelo(中二階)などが入り、さらにずれることもあります。部屋を探すときは「日本で言う何階か」を現地で確かめましょう。
参考:RAE: Diccionario「planta」(planta baja) / RAE: Diccionario「entresuelo」 / Cambridge Dictionary「ground floor」
🔟11番目からはふつうの数でOKテクニック

11番目以上にも序数はありますが、長くて難しいので、ふだんの会話ではふつうの数で代わりに言うのが自然です。RAE も「la planta diez(10階)」「la fila tres(3列目)」のような言い方を、ふつうの使い方としています。

🏢 階・列・席
la planta doce(12階)/ la fila quince(15列目)── 名詞の後ろにふつうの数
👑 王様の名前
Felipe VI = Felipe sexto(10までは序数で読む)
📜 世紀
siglo XXI = siglo veintiuno(11以上はふつうの数で読む)
覚え方
10番目まで=序数、11番目から=ふつうの数 と決めておけば、まず困りません。
参考:RAE: Los ordinales / RAE: DPD「ordinales」
🚀今日からできる一歩アクション
Q1. 「初めて」(for the first time)をスペイン語で。
答えpor primera vez(vez は女性名詞なので primera)
Q2. 「3日目」は el tercero día? el tercer día?
答えel tercer día(男性単数の前で -o が落ちる)
Q3. スペインのマンションの「2.º」は日本で言うと何階?
答え3階(planta baja が日本の1階なので1つずれる)
🎯 今日の一歩:階段やエレベーターで「序数カウント」

今日、階段を上るときやエレベーターに乗ったときに、日本の1階を planta baja、2階を primer piso、3階を segundo piso…と小声で数えてみましょう。
あわせて英語でも ground floor, first floor, second floor(イギリス式)と言ってみると、英語とスペイン語を一度に復習できます。
