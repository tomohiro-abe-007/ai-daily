規則動詞とは ─ 英語との比較でつかむ「活用」の感覚
基本概念
かんたん解説
動詞の活用（かつよう）とは、動詞の形が「だれが・いつ・どんな状況で」によって変わることです。 英語でも speak → speaks（3人称単数で -s がつく）のように少し変わりますが、変化はほぼ1か所だけ。 スペイン語は「私が・あなたが・彼が・私たちが・あなたたちが・彼らが」の6つで全部形が変わります。 でも、規則動詞（きそくどうし）は決まったパターン通りに変化するため、 一度パターンを覚えれば何百もの動詞に応用できます。

💡 スペイン語で嬉しいことが1つあります：動詞の語尾を見れば「誰が話しているか」がわかるので、 普段は主語（私・あなた・彼など）を省略できます。 「Hablo español.」だけで「私はスペイン語を話す」という意味が伝わります。 英語より情報が語尾に詰まっていて、実はシステマチック（規則的）です。

動詞の分解 ─ 語幹と語尾（不定詞から活用形を作る手順）
動詞の構造
かんたん解説
スペイン語の動詞は 「語幹（ごかん）＋ 語尾（ごび）」で成り立っています。 語幹は変わらない部分、語尾は人称によって変わる部分です。 不定詞（辞書に載っている形）から語尾の -ar / -er / -ir を取り除くと語幹が残ります。 あとはその語幹に、各人称の語尾をつければ完成です。
🔀 活用形を作る3ステップ（-ar 動詞 hablar の例）
① 不定詞
hablar
（話す）
→
② -ar を取る
habl-
（語幹）
→
③ 語尾をつける
hablo
（語幹 + -o = 私が話す）

💡 語幹は変わらない ─ これが「規則動詞」の強みです。 hablar の語幹 habl- は6つの活用形すべてで同じ。 変わるのは語尾だけ。だから語尾のパターンを覚えることが最優先です。
🟢
-ar 動詞の活用（hablar で覚える）
-ar 動詞
かんたん解説
-ar 動詞はスペイン語で最も多いタイプです。代表例 hablar（話す）の活用を覚えれば、 同じパターンの動詞すべてに応用できます。 語幹 habl- に下の表の語尾をつけるだけです。
📗 hablar（話す / to speak）─ 語幹: habl-
人称 活用形（語幹＋語尾） 英語 日本語
yo（私）I hablo I speak 私は話す
tú（あなた）you (singular) hablas you speak あなたは話す
él / ella（彼/彼女）he / she habla he/she speaks 彼/彼女は話す
nosotros（私たち）we hablamos we speak 私たちは話す
vosotros（あなたたち）you all ─ スペイン特有！ habláis you all speak あなたたちは話す
ellos / ellas（彼ら）they hablan they speak 彼らは話す
語尾まとめ -ar 動詞の語尾：-o / -as / -a / -amos / -áis / -an
語幹に -o, -as, -a, -amos, -áis, -an をつけるだけ。
yo の形（-o）は全タイプで共通 → まず "yo hablo" から始めよう！
📦 よく使う -ar 動詞（同じパターンで活用できる）
escuchar聞く
trabajar働く
estudiar勉強する
caminar歩く
comprar買う
necesitar必要とする
mirar見る
usar使う
llamar呼ぶ・電話する
tomar飲む・乗る
💡 スペインに住む予定なら vosotros（あなたたち）の形 -áis も大切です。 ラテンアメリカでは vosotros を使わず代わりに ustedes を使いますが、 スペイン本国では日常的に「¿Habláis español?（あなたたちはスペイン語を話しますか？）」のように使います。

🔵
-er 動詞の活用（comer で覚える）
-er 動詞
かんたん解説
-er 動詞の代表例は comer（食べる）。語幹は com-（= eat のイメージ）。 語尾は -ar とは少し違います。 -ar が -a 系の語尾、-er は -e 系の語尾と覚えると整理しやすいです。
📘 comer（食べる / to eat）─ 語幹: com-
人称 活用形（語幹＋語尾） 英語 日本語
yo（私）I como I eat 私は食べる
tú（あなた）you comes you eat あなたは食べる
él / ellahe / she come he/she eats 彼/彼女は食べる
nosotroswe comemos we eat 私たちは食べる
vosotrosyou all ─ スペイン特有 coméis you all eat あなたたちは食べる
ellos / ellasthey comen they eat 彼らは食べる
語尾まとめ -er 動詞の語尾：-o / -es / -e / -emos / -éis / -en
-ar と比べると：
・tú：-ar は -as、-er は -es（a → e に変わる）
・él：-ar は -a、-er は -e（同様）
・nosotros：-ar は -amos、-er は -emos（a → e）
→ -ar は「a 系」、-er は「e 系」と覚える！
📦 よく使う -er 動詞
beber飲む
leer読む
correr走る
aprender学ぶ
comprender理解する
vender売る
responder答える
💡 aprender（学ぶ）は語学学習者の必携動詞！
「Aprendo español.」→「私はスペイン語を学んでいます。」
「¿Aprendes inglés?」→「あなたは英語を学んでいますか？」
-er 動詞の活用をマスターしたら、この文がすぐ作れます。
🟣
-ir 動詞の活用（vivir で覚える）
-ir 動詞
かんたん解説
-ir 動詞の代表例は vivir（住む・生きる）。語幹は viv-。 -ir 動詞は -er 動詞と非常によく似ています！ 違いは nosotros（-emos vs -imos）と vosotros（-éis vs -ís）だけ。 スペインに住む予定なので、この2つの違いをしっかり確認しましょう。
📙 vivir（住む / to live）─ 語幹: viv-
人称 活用形（語幹＋語尾） 英語 日本語
yo（私）I vivo I live 私は住む
tú（あなた）you vives you live あなたは住む
él / ellahe / she vive he/she lives 彼/彼女は住む
nosotroswe vivimos we live 私たちは住む
vosotrosyou all ─ スペイン特有 vivís you all live あなたたちは住む
ellos / ellasthey viven they live 彼らは住む
📦 よく使う -ir 動詞
escribir書く
abrir開ける
recibir受け取る
subir上る・乗る
decidir決める
dividir分ける
💡 vivir は「スペインに住む」夢を語るための動詞。
「Quiero vivir en España.」→「私はスペインに住みたい。」
（quiero は "I want" の意味。vivir はここでは不定詞のまま使っています）
活用した形では「Vivo en Tokio.」→「私は東京に住んでいます。」
参考: 東京外国語大学 スペイン語モジュール ─ 動詞の現在形（er/ir 動詞）
📊
3タイプの語尾を並べて比べる ─ -er と -ir はほぼ同じ！
語尾まとめ
かんたん解説
3タイプを並べると、共通点と違いが一目でわかります。 yo（私）の語尾はどのタイプでも -o で同じ。 そして -er と -ir は nosotros と vosotros の語尾だけが違います。
📋 語尾比較マトリクス（語幹に加える部分）
人称 🟢 -ar 動詞
(hablar)		 🔵 -er 動詞
(comer)		 🟣 -ir 動詞
(vivir)
yo（私） -o -o -o
tú（あなた） -as -es -es
él / ella（彼/彼女） -a -e -e
nosotros（私たち） -amos -emos -imos
vosotros（あなたたち） -áis -éis -ís
ellos / ellas（彼ら） -an -en -en
🌟 表から読み取れる3つのポイント：
① yo は全タイプ -o ─ 最初に覚えるのはこれだけでOK！
② tú / él / ellos は -er と -ir で同じ ─ 2タイプの違いを覚える必要があるのは nosotros と vosotros の2か所だけ
③ -ar は全体的に "a 系"、-er/-ir は "e/i 系" ─ まず「-ar か、それ以外か」で大別できる
✅ よく使うパターン例
Hablo español.（私はスペイン語を話す）
¿Dónde vives?（どこに住んでいますか？）
Comemos juntos.（私たちは一緒に食べる）
¿Aprendéis japonés?（君たちは日本語を学んでいますか？）
⚠️ 初心者がよく間違えるパターン
× Yo hablos.（yo に -as をつけてしまう）
→ ✅ Yo hablo.

× Nosotros vivemos.（-er の語尾を使ってしまう）
→ ✅ Nosotros vivimos.
💡 最初は全部覚えようとしなくてOKです。 まず yo（私）と tú（あなた）の形から始めましょう。 「Hablo / Hablas」「Como / Comes」「Vivo / Vives」の6個を声に出せるだけで、 日常会話のかなりの部分に対応できます。

🎯 今日の一歩

この3文を声に出して5回言う：
「Hablo un poco de español.」（私は少しスペイン語を話します）

→ この3文に今日習った -ar/-er/-ir 動詞がすべて含まれています。

AIに送るプロンプト ─ 規則動詞の活用を練習する
I am a Japanese beginner learning Spanish. Today I studied regular verb conjugation (-ar, -er, -ir) in the present tense. Please help me practice with a short quiz: 1. Give me 5 Spanish verbs (mix of -ar, -er, -ir). For each, ask me to write the "yo" and "tú" forms. 2. After each answer, tell me if I am correct and briefly explain any mistakes in simple Japanese. 3. Then give me 2 short English sentences to translate into Spanish (use regular verbs only). Please start now.
→（意味）「日本語を母語とするスペイン語初心者です。今日は規則動詞（-ar/-er/-ir）の現在形を勉強しました。①スペイン語の動詞5つを出して yo と tú の活用形を答えさせてください ②答えるたびに正誤と簡単な日本語解説 ③英文2つをスペイン語に翻訳（規則動詞のみ）。始めてください。」
  • ✓ 英語のリズムで覚えるコツ： 英語は "I/you/he speak(s)" と主語を必ず言います。スペイン語は語尾が違うので主語なしでOK。 最初は "Yo hablo / Tú hablas" と主語つきで練習し、慣れたら省略してみましょう。
  • ✓ -ir 動詞は -er とほぼ同じと考える： nosotros（-imos）と vosotros（-ís）の2か所だけ意識すれば、あとは -er と同じパターンです。 この「覚える量を減らす」発想が継続の秘訣です。
  • ✓ まず yo と tú の2形を制する： 会話では「私が〜する・あなたが〜する」が圧倒的に多い。 この2つの活用形を確実に使えれば、会話の大部分がカバーできます。
🌟 今日は規則動詞の現在形（現在直説法）を学びました。
スペイン語の動詞には過去形・未来形・接続法など多くの活用がありますが、 すべての時制で「語幹＋語尾」の構造は同じ。今日の学習は全時制の土台です。 焦らず、まず現在形の yo / tú 形から毎日少しずつ積み上げましょう。

📝 今日のまとめ

🔧
動詞の構造は「語幹＋語尾」
不定詞から -ar/-er/-ir を取り除くと語幹が残る。あとは人称ごとの語尾をつけるだけ。
🟢
-ar 動詞
語尾：-o / -as / -a / -amos / -áis / -an
最も動詞が多い。hablar / escuchar / estudiar など。
🔵
-er 動詞
語尾：-o / -es / -e / -emos / -éis / -en
comer / beber / aprender / correr など。
🟣
-ir 動詞
語尾：-o / -es / -e / -imos / -ís / -en
vivir / escribir / abrir / recibir など。
💡
-er と -ir の違いは2か所だけ
nosotros（-emos vs -imos）と vosotros（-éis vs -ís）だけ。覚える量を最小化できる。
