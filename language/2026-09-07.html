🎯 今日のゴール：「もし」の接続法を「まるで〜のように」に応用する 動機づけ

09-05・09-06では、Si（もし）を使った「事実ではない仮定」を扱い、接続法過去（fuera）と接続法過去完了（hubiera sabido）という2つの形を作れるようになりました。実はこの2つの形は、Si以外の場面でもよく使われます。その代表が今日のテーマcomo si（まるで〜であるかのように）です。

como siは「事実ではないことを、たとえ話として言う」表現（言い換え：本当はそうではないのに、そうであるかのように振る舞う・見える様子を言うこと）です。英語のas if / as thoughとほぼ1対1で対応するので、これまで作った部品をそのまま使い回せます。

今日の範囲
ゴールは「まるで〜であるかのように」を英語（as if/as though）とスペイン語（como si）の両方で言えるようになり、09-05・09-06の接続法の形が「もし」だけでなくここでも使われることを理解することです。
🧠 基礎知識：como siがなぜ必ず接続法とセットなのか 基礎知識

como si（まるで〜のように）の後ろに続く内容は、実際には起きていないことです。「知っているかのように話す」なら、本当は知らない可能性が高いわけです。スペイン語では「事実ではないこと」を言うとき、現実を述べる直説法（言い換え：事実をそのまま言う普通の動詞の形）ではなく、接続法（言い換え：仮定・願望・非現実を表す特別な動詞の形）を使うというルールがあるため、como siの後ろは必ず接続法になります。

同時の見せかけ
Habla como si lo supiera todo.（まるで全部知っているかのように話す＝話している「その時」と同じタイミングの見せかけ）
それ以前の見せかけ
今日詳しく学ぶ。Actúa como si nada hubiera pasado.（まるで何も起こらなかったかのように振る舞う＝「振る舞っている時」より前の見せかけ）
つながりのポイント
09-05のfuera（接続法過去）と09-06のhubiera sabido（接続法過去完了）は、ここでもそのまま使えます。違いは「もし〜なら」ではなく「まるで〜のように」という意味で使うことだけです。部品は同じ、使い道が増えるイメージです。
🇬🇧 新しい知識①：英語のas if/as though＋過去形（同時の見せかけ） 新しい知識

文法解説サイトGrammaringによると、as if / as thoughに続く節が「現実ではない・ありそうにない状況」を表すとき、動詞は現在形ではなく過去形（過去のことを言っているのではなく、非現実を表す仮定法的な過去形）を使います。話しているタイミングと同じ時点の見せかけを表すときにこの形になります。

例文
She talks as if she knew everything.（彼女はまるで全部知っているかのように話す＝実際は知らないだろう）

as ifとas thoughはほとんど同じ意味で使われ、置き換え可能です。またbe動詞のときはフォーマルな文脈で単数でもwereを使う（as if she were rich）ことが多く、口語ではwasも使われます。

参考：AS IF / AS THOUGH（Grammaring）
✏️ 新しい知識②：スペイン語のcomo si＋接続法過去（同時の見せかけ） 新しい知識

RAE（スペイン王立アカデミー）の文法解説によると、como siの後ろに接続法過去（imperfecto de subjuntivo、09-05で作ったfuera/supieraなどの形）を置くと、「irrealidad simultánea（言い換え：主節の動詞と同じタイミングで起きている非現実）」を表します。

como si lo supiera
saber：知っているかのように
Habla como si lo supiera todo.
como si se tratara
tratarse：であるかのように
Lo tomó como si se tratara de una broma.
como si fuera
ser：であるかのように
09-05のfueraがここでも使える
💡 主節が過去でも「同時」は接続法過去のまま
Lo tomó como si se tratara de una broma.（それを、まるで冗談であるかのように受け止めた）のように、主節（Lo tomó）が過去でも、como si以下は主節と同じタイミングの話なので接続法過去のままです。「接続法過去＝今のこと」と決めつけないのがポイントです。
参考：Los tiempos del subjuntivo（RAE - Nueva gramática）
🔗 新しい知識③：スペイン語のcomo si＋接続法過去完了（それ以前の見せかけ） 新しい知識

Kwiziqの解説によると、como siの後ろに接続法過去完了（pluscuamperfecto de subjuntivo、09-06で作ったhubiera+過去分詞）を置くと、「irrealidad anterior（言い換え：主節の動詞より前に起きた非現実）」を表します。「まるで〜だったかのように」という、一段階前の見せかけです。

1
como si
（まるで〜のように）
+
2
09-06のhubiera
＋過去分詞
=
3
完成
como si hubiera
+過去分詞
例文
Actúa como si nada hubiera pasado.（まるで何も起こらなかったかのように振る舞う＝Actúa（今）よりも前に「何も起きなかった」ことにしている）
つながりのポイント
Lo tomó como si se hubiera tratado de una broma.（まるで冗談だったかのように受け止めた）のhubiera tratadoは、09-06のhubiera sabidoと全く同じ作り方（hubiera＋過去分詞）です。「もし」から「まるで」に使い道が変わっただけで、部品作りは同じです。
参考：Using the Pluperfect Subjunctive after "como si"（Kwiziq Spanish）
📊 英語⇔スペイン語 対応表 整理
役割英語スペイン語
同時の見せかけ（今日①②）as if/as though + 過去形como si + 接続法過去
それ以前の見せかけ（今日③）as if/as though + had + 過去分詞como si + hubiera + 過去分詞
例文（同時）She talks as if she knew everything.Habla como si lo supiera todo.
例文（それ以前）He acts as if nothing had happened.Actúa como si nada hubiera pasado.

「主節と同じタイミングか、それより前か」で形を選ぶ発想は、09-05・09-06のSi構文とまったく同じです。英語は過去形/had+過去分詞、スペイン語は接続法過去/接続法過去完了という、すでに知っている部品を「もし」から「まるで」に転用するだけです。

🙅 つまずきやすいポイント よくある誤解
① como siの後ろに直説法を使ってしまう
como siの後ろは事実ではないことを言うため、直説法（普通に事実を言う形）は使えません。Como si sabe todo.（×）ではなく、Como si supiera todo.（○）が正しい形です。
② 「接続法過去＝現在、接続法過去完了＝過去」と絶対時制で覚えてしまう
正しくは主節の動詞との相対関係です。「同じタイミングか」「それより前か」で選ぶのであって、話している瞬間が今か過去かとは別の話です（section4のLo tomó como si se tratara...の例を参照）。
③ 英語でas ifのbe動詞をhe/she/itなのにwasと決めつける
フォーマルな書き言葉では単数でもas if she wereのようにwereが好まれますが、口語ではwasもよく使われます。どちらも見かけることを知っておくと戸惑いません。

🎯 今日の一歩：「como si...」を1文作ってみる

最近見かけた「まるで〜みたいな」行動（例：まるで初めて聞いたかのように驚く、まるで何もなかったかのように振る舞う）を1つ選び、まず英語で"He/She acts as if..."にしてみましょう。次に、それが「同じタイミング」の見せかけならcomo si + 接続法過去、「それより前」の見せかけならcomo si + hubiera+過去分詞を使ってスペイン語にしてみます。動詞の活用に迷ったら、辞書やAI英会話・AIチューターのアプリ（料金・機能は変わるため公式で要確認）に確認しながら少しずつ増やしていきましょう。
