🎯今日のゴール動機づけ

スペインで暮らすと、大家さん・役所の窓口・近所のお年寄りなど、「目上の人や初対面の人」に話しかける場面が必ずあります。そこで使うのが señor / señora と don / doña です。日本語の「〜さん」「〜様」に近い働きをします。

👥4つの呼びかけの違い新しい知識
言葉読み(目安)意味つなぐもの
señorセニョール男性への敬称(Mr. / 〜さん)単独で呼びかけ可 / 苗字
señoraセニョーラ女性への敬称(Mrs. / 〜さん)単独で呼びかけ可 / 苗字
donドン男性への敬意をこめた呼び方名前(下の名)とセット
doñaドーニャ女性への敬意をこめた呼び方名前(下の名)とセット
ポイント
RAE(スペイン王立アカデミー=スペイン語の規範を示す機関)によると、don / doña は名前(下の名)の前に置く礼儀正しい呼び方で、例は don Francisco、doña María。また、こうした敬称は文中では小文字で書くのが原則です。
参考:RAE: Las formas de tratamiento / RAE: don

🌉英語とのブリッジ:Mr. / Ms. とどう違う?ブリッジ
英語 → スペイン語
Excuse me, sir. → Perdone, señor.
Mr. Garcia → señor García
(名前に敬意) → don Miguel / doña Carmen

英語の Mr. / Ms. は苗字につけるのが基本ですが、スペイン語には下の名につける don / doña という、英語にない形があります。日本語の感覚では「ミゲルさん」に少し敬意を足した感じ。年上の人や地域の顔役に使われてきた、というのが一般的なイメージです。

💡 かんたんな見分け
señor / señora = 「Mr. / Ms.」に近い。don / doña = 名前に敬意を足す。迷ったら señor / señora + usted で失礼になることはまずありません。
🙅つまずきやすいポイントよくある誤解
① don + 苗字 にしない
don / doña は下の名の前。「don García」ではなく「señor García」または「don Miguel」。
② doña の ñ
doña は「ドーニャ」。ñ は eñe(エニェ)で、n ではありません。昨日の文字名の復習にもなります。
③ 地域・世代で感覚が違う
使う頻度や、どれくらい改まって聞こえるかは国・地域・世代で差があります。最初は聞こえた通りにまねるのが安全です。

🎯 今日の一歩:丁寧な呼びかけを3つ声に出す

次の3文を、口に出して各3回言いましょう:
Buenos días, señor. / Perdone, señora. / Mucho gusto, doña Carmen.
英語でも Excuse me, sir. / ma'am. を同じように言ってみると、2つの言語の対応が身につきます。
