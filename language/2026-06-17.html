形容詞とは ─ 英語との比較で「一致」の感覚をつかむ
基本概念
かんたん解説
形容詞（けいようし）とは、名詞を説明する言葉です。英語では "big house"（大きな家）・"big cars"（大きな車）のように、形容詞は big のまま一切変わりません。 スペイン語では、形容詞は後ろにある名詞の「性（男性・女性）」と「数（単数・複数）」に合わせて形を変えます。 これを文法用語で 一致（いっち）/ concordancia（コンコルダンシア）と言います。 難しそうに聞こえますが、パターンは決まっており、一度覚えれば自動的に判断できるようになります。

⚖️
名詞の性（せい）─ 男性名詞と女性名詞の見分け方
名詞の性
かんたん解説
スペイン語のすべての名詞は「男性（masculino）」か「女性（femenino）」のどちらかに属します。 これは生き物の雌雄とは必ずしも一致せず、libro（本）は男性名詞、casa（家）は女性名詞です。 見分けの基本ルール：語尾が -o なら男性、-a なら女性が多い。 また、一緒に使う冠詞（el か la）を見れば性が一目でわかります。
el 男性名詞（masculino）
el librothe book
el chicothe boy
el cochethe car
el díathe day
el problemathe problem
🔑 語尾 -o、-ma、-pa で終わる語は男性が多い
（例外：el día は -a で終わるが男性）
la 女性名詞（femenino）
la casathe house
la chicathe girl
la ciudadthe city
la lecciónthe lesson
la manothe hand
🔑 語尾 -a、-ción、-dad、-tad で終わる語は女性が多い
（例外：la mano は -o で終わるが女性）
実践のコツ 名詞は「冠詞ごと」セットで覚えよう
英語学習でも "a book" "the house" とセットで覚えますよね。スペイン語も同じ。
libro（本）ではなく el libro（男性）、
casa（家）ではなく la casa（女性）と冠詞ごとセットで覚えるのが最短の近道です。
そうすると形容詞の形も自然に決まります。
💡 例外もありますが、スペイン語の名詞の性は 語尾の -o / -a で7〜8割 の確率で判断できます。 まず「-o なら el（男性）、-a なら la（女性）」のルールを体に入れ、例外は出会ったときに覚えていきましょう。 いきなり全部暗記しようとしないことが長続きの秘訣です。

形容詞の4つの形 ─ -o/-a/-os/-as で変わる「-o 型」
形容詞の変化
かんたん解説
スペイン語で最もよく使う形容詞は、語尾が -o で終わる「-o 型」です。 このタイプは名詞の性・数に合わせて 4 つの形を持ちます。 男性単数 (-o)・女性単数 (-a)・男性複数 (-os)・女性複数 (-as) です。 代表例として alto（背が高い・tall）で全形を確認しましょう。
📊 形容詞 alto（背が高い）の4つの形
性 ╲ 数
🔵 男性（masculino）
el, un と一緒に使う名詞
🩷 女性（femenino）
la, una と一緒に使う名詞
単数
（sg.）
alto tall (man) el chico alto
（背が高い男の子）
alta tall (woman) la chica alta
（背が高い女の子）
複数
（pl.）
altos tall (men/mixed) los chicos altos
（背が高い男の子たち）
altas tall (women) las chicas altas
（背が高い女の子たち）
🌟 ルールまとめ（-o 型形容詞）：
・男性単数 ─ そのまま（-o）：alto, bueno, nuevo
・女性単数 ─ -o を -a に変える：alta, buena, nueva
・男性複数 ─ -o に -s をつける（-os）：altos, buenos, nuevos
・女性複数 ─ -a に -s をつける（-as）：altas, buenas, nuevas
📦 よく使う -o 型形容詞（男性単数形で掲載・女性は -a に変えるだけ）
alto / altatall背が高い
bajo / bajashort, low低い・背が低い
bueno / buenagood良い
malo / malabad悪い
nuevo / nuevanew新しい
viejo / viejaold古い・年老いた
bonito / bonitapretty, niceかわいい・きれいな
pequeño / pequeñasmall, little小さい
blanco / blancawhite白い
negro / negrablack黒い
rojo / rojared赤い
delgado / delgadathin, slim細い・スリムな
✅ 正しい一致の例
el libro nuevo（新しい本）
→ libro は男性 → nuevo（-o）

la casa nueva（新しい家）
→ casa は女性 → nueva（-a）

los coches rojos（赤い車たち）
→ coche は男性複数 → rojos（-os）
⚠️ よくある間違い
× la chica alto
→ chica は女性なのに男性形を使っている
✅ la chica alta

× los chicos nueva
→ 男性複数なのに女性単数形を使っている
✅ los chicos nuevos
💡 まず「el なら -o、la なら -a」の基本から始めましょう。 複数形の -s はあとから自然につきます。最初の一歩は単数の -o/-a だけ意識すれば十分です。

🔄
語順の違い ─ スペイン語では形容詞は名詞の後ろ！
語順
かんたん解説
英語では「形容詞 → 名詞」の順（a big house）ですが、スペイン語では基本的に「名詞 → 形容詞」の順（una casa grande）になります。 形容詞は後ろから名詞を修飾（せつめい）するのがスペイン語の標準です。 これは最初はとても不思議に感じますが、日本語の「大きな家」→「家　大きな」と思えば逆の感覚がつかみやすいかもしれません。
🇬🇧 英語の語順：形容詞 → 名詞 ADJ + NOUN
big+house
→ a big house（大きな家）

red+car
→ a red car（赤い車）

good+book
→ a good book（良い本）
🇪🇸 スペイン語の語順：名詞 → 形容詞 NOUN + ADJ
casa+grande
→ una casa grande（大きな家）

coche+rojo
→ un coche rojo（赤い車）

libro+bueno
→ un libro bueno（良い本）
補足 一部の形容詞は名詞の前に置くこともある
bueno/malo（良い・悪い）、grande（大きい）、数を表す形容詞などは名詞の前に置くことがあります。
・un buen amigo（良い友人）← bueno が前に来て buen に短縮
・un gran hombre（偉大な人）← grande が前に来て gran に短縮
これらは例外として後から覚えればOK。まずは「名詞の後ろ」が基本と覚えましょう。

🔵
性で変化しない形容詞 ─ -e 型・子音型
特殊パターン
かんたん解説
すべての形容詞が4形に変化するわけではありません。 語尾が -e や子音（b, l, z, r など）で終わる形容詞は、男性・女性で形が変わりません（ただし複数形には -s または -es をつけます）。 つまり、grande（大きい）は男性名詞にも女性名詞にも grande のまま使えます。-o 型よりも楽です！
形容詞の語尾タイプ 男性単数 女性単数 男性複数 女性複数
🟢 -o 型
bueno（良い）		 bueno buena buenos buenas
🔵 -e 型
grande（大きい）		 grande grande ← 同じ！ grandes grandes ← 同じ！
🟠 子音型
azul（青い）		 azul azul ← 同じ！ azules azules ← 同じ！

🧩
英語知識が活きる形容詞 ─「同族語（コグネイト）」を活用しよう
英語×スペイン語
かんたん解説
英語とスペイン語はともにインド・ヨーロッパ語族に属し、ラテン語という共通の祖先を持ちます。 そのため、英語とスペイン語には意味も形もよく似た単語（同族語：コグネイト）が大量に存在します。 形容詞に限らず、英語で知っている単語がスペイン語でもほぼ同じ形で使えることが多いです。 これこそが「英語を先に学んでからスペイン語に移る」最大のメリットです！
英語 → スペイン語 コグネイト形容詞リスト
important→importante重要な
intelligent→inteligente賢い
interesting→interesante面白い・興味深い
different→diferente異なる
natural→natural自然な
normal→normal普通の
popular→popular人気のある
romantic→romántico / románticaロマンチックな
historic→histórico / histórica歴史的な
fantastic→fantástico / fantástica素晴らしい
typical→típico / típica典型的な
excellent→excelente優れた・素晴らしい
パターン解説 英語の語尾をスペイン語に変換するコツ
英語の形容詞をスペイン語に変換するパターンがあります：
・英語 -tic → スペイン語 -tico/-tica：romantic → romántico
・英語 -ent → スペイン語 -ente：different → diferente
・英語 -al / -ar → スペイン語 そのまま：natural → natural, popular → popular
・英語 -ous → スペイン語 -oso/-osa：famous → famoso（有名な）
完全に一致するわけではありませんが、英語の語尾を見ると「たぶんこうかな？」と予測できます。予測して確認する習慣が語彙力を爆発的に伸ばします。
🗣️ コグネイト形容詞を使った文の例
🏛️
Madrid is very historic. →
Madrid es muy histórica.
（es = is, muy = very。Madrid は女性名詞なので histórica）
📚
This lesson is interesting. →
Esta lección es interesante.
（esta = this, lección は女性だが interesante は -e 型なので変化なし）
🎉
The food is fantastic! →
¡La comida es fantástica!
（comida = food, 女性名詞なので fantástica）
💡 英語でまず意味を理解してからスペイン語を覚えると、語彙の定着が2倍速くなります。 英語の「important」を知っている人はスペイン語の「importante」をほぼゼロから覚えなくていい。 これが「英語→スペイン語」の順番で学ぶ最大のご利益（りやく）です！

⚖️
形容詞は名詞に「一致」する
英語では変化しない形容詞が、スペイン語では名詞の性（男・女）と数（単・複）に合わせて4つの形を持つ。
🔵🩷
名詞の性：-o は男性、-a は女性が多い
el libro（男）, la casa（女）のように冠詞を見れば性がわかる。名詞は冠詞とセットで覚えよう。
📐
-o 型形容詞の4形
alto / alta / altos / altas。男性単数 -o → 女性単数 -a → 複数は -s を追加するだけ。
🔄
語順：名詞の後ろが基本
英語「big house」→ スペイン語「casa grande」。形容詞は名詞の後ろに置く。
🔵
-e 型・子音型は性で変化しない
grande, importante, azul などは男女共通。-o 型より楽！複数は -s/-es を追加。
🧩
英語のコグネイトが強い味方
important → importante, interesting → interesante など英語の語彙がそのまま活きる。これが英語→スペイン語の強み！
