used to / be used to / get used toは見た目がそっくりですが、意味も文法もまったく別物です。海外生活では「まだ慣れていません」「だんだん慣れてきました」をよく言うので、ここで整理しておくと便利です。

🔍 なぜ -ing になるの? 仕組み

used to(昔〜した)の to は「動詞の前に付く to」です。でも be/get used to の to は前置詞(ぜんちしほう・名詞の前に置く語。at や in の仲間)です。前置詞の後ろに動詞を置くときは -ing にします。

昔の習慣・状態?
→ used to + 原形:I used to live here.
今、慣れている?
→ be used to + 名詞/-ing:I'm used to living here.
慣れてきている途中?
→ get used to + 名詞/-ing:I'm getting used to living here.
💡 見分けテスト
to を the cold や it に置き換えられれば前置詞です(I'm used to it. は自然、I used to it. は不自然)。
参考:Test-English: Used to, be used to, get used to／Ella Language: used to / be used to / get used to
🌉 スペイン語とのブリッジ ブリッジ

スペイン語にも同じ発想があります。「慣れている」は estar acostumbrado/a a、「慣れてくる」は acostumbrarse a。a(前置詞)の後ろに名詞または不定詞(動詞の原形)を置きます。スペイン語は前置詞の後ろの動詞が -ing ではなく原形(不定詞)になる点が英語との違いです。

意味英語スペイン語
寒さに慣れているI'm used to the cold.Estoy acostumbrado al frío.
早起きに慣れてきたI'm getting used to getting up early.Me estoy acostumbrando a madrugar.

※ 女性が言うときは acostumbrada。acostumbrarse は再帰動詞(7/1の回)なので me が付きます。

🙅 つまずきやすいポイント よくある誤解
① I'm used to live here. は誤り
be used to の後ろは -ing:I'm used to living here.
② 「昔は〜した」に be used to を使う
昔の習慣は used to + 原形です(I used to play soccer.)。
③ 疑問・否定の形の混同
used to の否定・疑問は didn't use to / Did you use to ...?(use に戻る)という説明が一般的です。be/get used to は普通の be動詞・get の文なので、I'm not used to ... のようになります。
