🎯今日のゴール動機づけ

昨日の「個人の a」と、前置詞の a(「〜に」)はつづりが同じでも役割が別です。María の前に a があっても、María が見られる相手なのか受け取る相手なのかで意味が変わります。

2つ
a の役割
個人の a / 「〜に」の a
lo / la
直接目的語の代名詞
Veo a María → La veo.
le / les
間接目的語の代名詞
a María → Le doy…
参考:Unit 4: Personal a / ‘A’ personal / 直接目的語代名詞 / QuillBot: 直接・間接目的語
⚖️2つの a の違い新しい知識
個人の a「〜に」の a(間接目的語)
例文Veo a María.Doy el libro a María.
María の役割見られる人(直接目的語)受け取る人(間接目的語)
日本語の目安「〜を」「〜に」
代名詞La veo.Le doy el libro.
ポイント
用語の言いかえ:直接目的語=動作を直接受ける相手(〜を)、間接目的語=受け取る・恩恵を受ける相手(〜に)。
参考:Unit 4: Personal a / ‘A’ personal / 直接目的語代名詞 / QuillBot: 直接・間接目的語
🧭見分けフロー(代名詞テスト)仕組み
1
「a + 人」を見つける
➡️
2
日本語で「〜を」か「〜に」か考える
➡️
3
lo/la か le かで置きかえて確かめる
La / Lo に置きかえられる
→ 個人の a:Veo a María. → La veo.
Le に置きかえられる
→ 「〜に」の a:Doy el libro a María. → Le doy el libro.
1文に a + 人が2つ
→ 直接目的語の人の a は省かれることがある(受け取る人の a を優先)。例:Presento Juan a María.(とされる教材が多い)
💡 ひとこと
「Le doy el libro a María.」のように le と a María を両方言うのは普通です(9/1 の与格の重複)。le が間接目的語を予告しています。

🌉英語とのブリッジブリッジ

英語では see Maria(前置詞なし)と give the book to Maria(to あり)で形が違います。スペイン語の「〜に」の a は英語の to に近い役割です。

英語 → スペイン語
I see Maria → Veo a María(個人の a。英語に対応語なし)
I give the book to Maria → Doy el libro a María(to に相当)
I give Maria the book → Le doy el libro a María
参考:Unit 4: Personal a / ‘A’ personal / 直接目的語代名詞 / QuillBot: 直接・間接目的語
🙅つまずきやすいポイントよくある誤解
① 「a がある=to」と決めつける
Veo a María の a は「〜に」ではありません。英語の to に直訳しないこと。
② 不特定の人
Busco un médico.(誰でもよい医者)のように、不特定の人は個人の a を付けないのが基本です。
③ 教材による説明の幅
2人が出てくる文の a の扱いは教材で説明が少し異なります。まずは「代名詞テスト」で判断し、細部は使いながら慣れましょう。
参考:Unit 4: Personal a / ‘A’ personal / 直接目的語代名詞 / QuillBot: 直接・間接目的語
