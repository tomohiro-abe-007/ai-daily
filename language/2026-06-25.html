英語との違い ── 2段階 vs 3段階
全体像

「この本」「その本」「あの本」のように、ものや人を指す言葉を 指示詞（しじし）（英語：demonstrative adjective）といいます。
日本語には「この・その・あの」の3段階がありますが、 英語は「this / that」の2段階しかありません。
スペイン語はなんと日本語と同じ3段階！ 日本語感覚で理解できる、英語学習者には嬉しいポイントです。

2
英語の段階数
this（近い）
that（遠い）
3
スペイン語の段階数
este・ese・aquel
（日本語と同じ！）
4
性・数の変化パターン
男性単数・女性単数
男性複数・女性複数

日本語で考えると
「コ・ソ・ア」の体系（こそあど言葉）が日本語にありますね。 スペイン語も同じ発想で3段階に分かれています。
英語は「this / that」の2段階しかないので、 日本語話者はスペイン語の指示詞をより自然に感じ取れます！

🔵
este / esta ── 「この」（自分の近く）
近距離

este（エステ）は、話し手（自分）のすぐそばにあるものを指します。 英語の "this / these" に対応します。
後ろにつく名詞の性（男性・女性）と数（単数・複数）に合わせて形が変わります。

　 男性（masculino） 女性（femenino）
単数（singular） este
エステ		 esta
エスタ
複数（plural） estos
エストス		 estas
エスタス
例文で確認 este / esta の使い方
🔵 Este libro es interesante.（この本は面白い）
libro（本）= 男性名詞 → este
🔵 Esta camisa es muy cara.（このシャツはとても高い）
camisa（シャツ）= 女性名詞 → esta
🔵 Estos zapatos son cómodos.（この靴は履きやすい）
zapatos（靴）= 男性複数 → estos
🔵 ¿Cuánto cuestan estas manzanas?（このリンゴはいくらですか？）
manzanas（リンゴ）= 女性複数 → estas
✏️ 男性名詞は -o / -os、女性名詞は -a / -as で終わるものが多い。
名詞の性がわからないときは、冠詞（el=男性 / la=女性）で確認！
参考：SpanishDict — Demonstrative Adjectives and Pronouns
🟠
ese / esa ── 「その」（相手の近く）
中距離

ese（エセ）は、聞き手（相手）の近くにあるものを指します。 英語の "that / those" に近いですが、特に「相手のそばにある」イメージです。
お店で「そのパンをください」とか「あなたの手に持っているもの」を指すときに使います。

　 男性（masculino） 女性（femenino）
単数（singular） ese
エセ		 esa
エサ
複数（plural） esos
エソス		 esas
エサス
例文で確認 ese / esa の使い方
🟠 Ese café está muy rico.（そのコーヒーはとても美味しい）
café（コーヒー）= 男性名詞 → ese
🟠 ¿Me das esa llave?（そのカギを渡してもらえますか？）
llave（カギ）= 女性名詞 → esa
🟠 Esos son mis amigos.（あの人たちは私の友達です）
男性複数（または混合グループ）→ esos
🟠 ¿Conoces esas tiendas?（あのお店たちを知っていますか？）
tiendas（お店）= 女性複数 → esas
英語→スペイン語のブリッジ
英語では "that" が ese と aquel の両方に対応します。 スペイン語に移るときに「thatが2種類になる」と覚えるのがポイント。
相手の手元・相手の近く → ese
遠く見える場所 → aquel
参考：SpanishDict — Demonstrative Adjectives and Pronouns ／ Duolingo Blog — Demonstrative pronouns in Spanish
🟣
aquel / aquella ── 「あの」（遠くにある）
遠距離

aquel（アケル）は、話し手・聞き手どちらからも遠い場所にあるものを指します。 山・川・遠い建物など「あそこの〜」と指す場面で使います。
また過去の遠い出来事を回想するときにも使われます（「あのとき」のイメージ）。

　 男性（masculino） 女性（femenino）
単数（singular） aquel
アケル		 aquella
アケリャ
複数（plural） aquellos
アケリョス		 aquellas
アケリャス
例文で確認 aquel / aquella の使い方
🟣 Aquel edificio es muy antiguo.（あの建物はとても古い）
edificio（建物）= 男性名詞 → aquel
🟣 Aquella montaña es muy alta.（あの山はとても高い）
montaña（山）= 女性名詞 → aquella
🟣 Aquellos tiempos eran difíciles.（あの頃は大変だった）
tiempos（時代）= 男性複数 → aquellos
🟣 ¿Ves aquellas estrellas?（あの星たちが見える？）
estrellas（星）= 女性複数 → aquellas
✏️ 発音のコツ： ll（エリェ）はスペインでは「リャ・リョ」の音に近い発音です。
aquella → アケリャ、aquellos → アケリョス と覚えましょう。
参考：SpanishDict — Demonstrative Adjectives and Pronouns
📊
全形まとめ表（性・数の変化）
まとめ

3種類すべての指示詞と、その性・数変化をまとめました。 縦が距離感（近・中・遠）、横が性数（男単・女単・男複・女複）です。 全部で12の形があります。

距離感 日本語 男性単数 女性単数 男性複数 女性複数
🔵 近（自分の近く） この・これらの este esta estos estas
🟠 中（相手の近く） その・それらの ese esa esos esas
🟣 遠（二人から遠い） あの・あれらの aquel aquella aquellos aquellas
形の法則に注目
どの距離でも変化パターンは同じ：
  男性単数 → そのまま（este / ese / aquel）
  女性単数 → 語尾が -a（esta / esa / aquella）
  男性複数 → 語尾が -s（estos / esos / aquellos）
  女性複数 → 語尾が -as（estas / esas / aquellas）
「性・数で変わるルール」を1回覚えると3種類すべてに使えます。
⚠️ アクセント記号について（よくある疑問）
古いスペイン語の参考書や教材には éste, ése, aquél のようにアクセント記号がついた形が登場することがあります。 これは形容詞（名詞を修飾）と代名詞（単独で使う）を区別するために使われていたものです。 ただし 2010年以降は RAE（スペイン王立語学アカデミー）がアクセント記号なしを推奨しており、 現代のスペイン語では通常アクセントなしで書きます。
参考：Real Academia Española — Diccionario Panhispánico de Dudas: este ／ SpanishDict — Demonstrative Adjectives

日本語・英語との比較 ── 覚え方のコツ
英語→スペイン語

3言語を並べると、日本語話者にとって覚えやすい理由がはっきり見えます。

距離感 日本語 英語 スペイン語
近い（自分のそば） この / これ
コ系		 this
（近）		 este / esta
estos / estas
中間（相手のそば） その / それ
ソ系		 （thatで代用） ese / esa
esos / esas
遠い（二人から遠い） あの / あれ
ア系		 that
（遠）		 aquel / aquella
aquellos / aquellas
英語→スペイン語のブリッジ
英語の学習で「this ＝ 近い、that ＝ 遠い」を覚えているなら、 スペイン語では 「that が ese（相手の近く）と aquel（遠い）の2つに分かれる」 と考えるだけです。
日本語の「その vs あの」の使い分け感覚を思い出せば、 日本語ネイティブにはスペイン語の3段階がむしろ自然に感じるはずです。
お店・街中での実用フレーズ スペインで使う場面
🔵 Quiero este pan, por favor.
（このパンをください）← 目の前のパンを指して
🟠 ¿Puedo ver ese bolso?
（そのバッグを見せてもらえますか？）← 店員の持っているものを指して
🟣 ¿Cómo se llama aquel edificio?
（あの建物は何と言いますか？）← 遠くの建物を指して
🔵 Esta calle es muy bonita.
（この通りはとても綺麗ですね）← 今いる通りを指して
参考：Duolingo Blog — Demonstrative pronouns in Spanish ／ Preply — Spanish Demonstrative Adjectives

今日からできる一歩
アクション
🎯 今日のアクション
部屋の中のものを指して「este / ese / aquel ＋ 名詞」で5文作ってみる。

目の前にあるもの（スマホ・本・カップ…）を手に持ったり、視線を向けながらスペイン語で声に出してみましょう。

例：
  Este teléfono es mío.（この電話は私のです）
  Esta taza está caliente.（このカップは熱い）
  Aquella ventana es grande.（あの窓は大きい）

名詞がわからないときはスマートフォンの辞書やAIチャットで調べてかまいません。 「指さしながら口に出す」ことで、距離感と形が同時に体に入ります。
次のステップ① 「名詞の性」と指示詞をセットで覚える
新しいスペイン語単語を覚えるとき、冠詞（el / la）とセットで覚えましょう。
el libro（本）→ este libro / ese libro / aquel libro
la mesa（机）→ esta mesa / esa mesa / aquella mesa
冠詞の el → este/ese/aquel、la → esta/esa/aquella と対応しています。
次のステップ② 英語日記をスペイン語に変換してみる
英語で "This book is interesting. That café looks nice." と書いたあと、 スペイン語に変換してみましょう。
  → Este libro es interesante. Ese café parece bonito.
英語の this/that → スペイン語の este/ese への変換練習 が自然と身につきます。
英語の基礎固め 英語の demonstrative も同時強化
英語でも "this / that / these / those" の使い分けに自信がない場合は、 スペイン語と並べて練習するチャンスです。
this book → este libro / that book → ese libro or aquel libro
英語とスペイン語を対で覚えると定着が速くなります。
